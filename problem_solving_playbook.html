Part 1: The Basics - How Computers "Think" About Efficiency

Before diving into complex algorithms, it's crucial to understand how we measure their performance. We use "Big O Notation" to describe how an algorithm's runtime (Time Complexity) or memory usage (Space Complexity) scales with the size of the input data.

Space Complexity (The "Memory Usage" of Your Code)

Space complexity tells you how much **extra memory** your algorithm needs as the input size grows. We usually talk about "auxiliary space," which means the memory used *beyond* the input itself.

Why it's important:

If your algorithm uses too much memory, it can crash or slow down the system, especially for large inputs.

Common Notations:

Similar to time complexity, using Big O. O(1) space is ideal (constant memory), while O(N) means memory grows with input.
